Brand Colours

The palette that defines Tembusu across all channels
Primary
#005a3d

RGB (0, 90, 61) · CMYK (100, 0, 32, 65) · HSL (160°, 100%, 18%)

⚠️ Pale Green Restriction Do not use Pale Green (#b9e4d4) for borders, line dividers, or thin strokes — it is too light to provide sufficient contrast. Use Emerald Green for all border and divider applications.

Typography

Font hierarchy for print and digital
Font Pairing Rationale: Vollkorn (elegant serif) for headers + Inter (clean sans-serif) for body creates a professional balance between traditional finance trustworthiness and modern fintech innovation.
Heading Levels
Heading Level One
Vollkorn 32pt Emerald Green #005a3d Fallback: Georgia, serif
Heading Level Two
Vollkorn 24pt Emerald Green or Charcoal Fallback: Georgia, serif
Heading Level Three
Vollkorn 18pt Charcoal #2E2E2E Fallback: Georgia, serif
Body Text
Tembusu Financial Services provides fast, flexible financing solutions for businesses and individuals across Singapore. With over $1 billion in transactions funded and a team of experienced specialists, we deliver results when banks can't — or won't.
Inter 12pt Charcoal #2E2E2E Line-height: 1.3 Fallback: Arial, sans-serif
Font Sources
CSS — Google Fonts Import
/* Import both brand fonts */ @import url('https://fonts.googleapis.com/css2?family=Vollkorn:wght@400;600;700&family=Inter:wght@400;500;600&display=swap'); /* Apply typography */ h1, h2, h3 { font-family: 'Vollkorn', Georgia, serif; color: #005a3d; } body, p, li { font-family: 'Inter', Arial, sans-serif; font-size: 12pt; color: #2E2E2E; line-height: 1.3; }

Logo Usage

Placement, spacing, and background rules
Logo Versions
Full-colour on light
White on dark
☀️

Full-Colour Logo

Use on light backgrounds (white, beige, light grey). Primary logo for most applications. Maintains brand recognition.

🌙

White Logo

Use on dark backgrounds (Emerald Green, Bottle Green, Charcoal, gradients, photography). Ensures visibility and contrast.

📏

Clear Space

Maintain minimum 10px clear space around all sides of the logo. No text, graphics, or other elements within this exclusion zone.

Clear Space Diagram
10px ↓ ↑ 10px 10px → ← 10px

The dashed border indicates the minimum exclusion zone. No elements may enter this area.

Logo Formats Available
🖼️

Landscape

Horizontal orientation. Best for headers, email signatures, and wide-format placements.

📱

Portrait

Stacked orientation. Best for social media profiles, mobile headers, and square placements.

⬡

Icon

Mark only — no wordmark. Best for favicons, app icons, watermarks, and small-format placements.

Gradients

For digital use only — web, apps, and digital artwork
⚠️ Digital Only Gradients are strictly for digital use (web pages, apps, digital graphics). Never apply gradients in Word documents, PDFs, or PowerPoint slides — use flat brand colours instead.
Gradient 1 — Emerald Depth
Hero sections, card backgrounds, digital banners. Dark-to-rich emerald transition conveying depth and growth.
#063222 → #005a3d
Gradient 2 — Yellow Glow
Accent banners, CTAs, highlight sections. High energy — use sparingly for emphasis.
#e3ef26 → #f6ff6c
CSS Implementation
CSS — Gradient Variables
:root { /* Gradient 1: Emerald Depth */ --tembusu-gradient-1: linear-gradient(135deg, #063222, #005a3d); /* Gradient 2: Yellow Glow */ --tembusu-gradient-2: linear-gradient(135deg, #e3ef26, #f6ff6c); } /* Usage */ .hero-section { background: var(--tembusu-gradient-1); } .cta-banner { background: var(--tembusu-gradient-2); }

Accessibility

Contrast ratios, font sizing, and readability standards
Colour Contrast Compliance
CombinationPreviewWCAG RatingUse Case
Emerald Green on White Aa AAA ✓ Headings, links, key text
Charcoal on White Aa AAA ✓ Body text, paragraphs
White on Emerald Green Aa AA ✓ Buttons, headers on emerald
Charcoal on Pale Green Aa AA ✓ Text on Pale Green backgrounds
Charcoal on Beige Aa AAA ✓ Text on Beige backgrounds
White on Bottle Green Aa AAA ✓ Footer text, dark sections
Font Sizing Standards
📝

Minimum Body Text

12pt minimum for all body text across all channels — print and digital. Never go below this.

↕️

Line Spacing

1.3 line-height minimum for body text. Increases readability, especially in dense financial content.

📊

Clear Hierarchy

Always maintain the H1 → H2 → H3 → Body progression. Never skip heading levels — visual hierarchy helps readers scan.

Component Styling

UI patterns for web, presentations, and documents
Web Components
🔘

Buttons

Emerald Green background, white text. Hover state: Bright Yellow accent. Border-radius: 8px. Min padding: 10px 20px.

🔗

Links

Emerald Green text colour. Underline on hover. No underline at rest. Never use blue for links.

🃏

Cards

White background, subtle box-shadow (0 2px 12px rgba(0,0,0,0.06)). Emerald Green border or border-top on hover/active states.

Presentation Slides (PPTX)

Title Slides

Background: Emerald Green (#005a3d)
Title text: White, Vollkorn 32pt
White logo in top-right or bottom-right
Bright Yellow accent sparingly for subtitles

Content Slides

Background: White, Beige, or Pale Green
Headers: Emerald Green, Vollkorn
Body: Charcoal, Inter 12pt
Full-colour logo in consistent position

Documents (DOCX / PDF)
📄

Cover Page

Logo at top (10px spacing). Title: Vollkorn 32pt Emerald. Subtitle: Inter 14pt Charcoal. Date: Inter 10pt Charcoal.

📊

Tables

Headers: Emerald Green background, white text. Alternating rows: White and Beige. Borders: Emerald Green only.

📑

Charts & Graphs

Primary data series: Emerald Green. Accent series: Bright Yellow. Supporting: Greys. Ensure high contrast.

Do's & Don'ts

Common mistakes and best practices
Colour Usage

✓ Do

Use Emerald Green as the dominant brand colour
Use Bright Yellow sparingly — accents and CTAs on dark backgrounds only
Use Pale Green for light section backgrounds
Use Bottle Green for footers and deep dark sections
Use Charcoal (#2E2E2E) for all body text — never pure black
Keep social media button colours reserved for their respective platforms

✗ Don't

Use Pale Green for borders, line dividers, or thin strokes
Use Bright Yellow as a large background fill
Place light text on Bright Yellow — always use dark text (Charcoal or Bottle Green)
Substitute WhatsApp/Messenger/Instagram colours for general UI
Use pure black (#000000) for text — always use Charcoal
Use off-brand greens or blues in place of Emerald Green
Logo Usage

✓ Do

Use the full-colour logo on light backgrounds
Use the white logo on dark or gradient backgrounds
Maintain 10px minimum clear space on all sides
Keep the logo proportions consistent — never stretch or distort

✗ Don't

Place the full-colour logo on dark backgrounds
Place the white logo on light or white backgrounds
Crop, rotate, or add effects (shadow, glow, outline) to the logo
Place text, icons, or other elements within the 10px exclusion zone
Typography

✓ Do

Use Vollkorn for all headings (H1, H2, H3)
Use Inter for all body text, labels, and captions
Maintain the heading size hierarchy: 32pt → 24pt → 18pt → 12pt
Use 1.3 line-height minimum for body text

✗ Don't

Use decorative or display fonts not in the brand system
Go below 12pt for any body text
Skip heading levels (e.g. H1 straight to H3)
Use all-caps for body text — headings only when appropriate
Gradients & Digital

✓ Do

Use gradients in web pages, digital ads, and app interfaces
Use Emerald Depth gradient for hero sections and large dark areas
Use Yellow Glow gradient sparingly for high-impact CTA elements

✗ Don't

Use gradients in PowerPoint, Word, or PDF documents
Create custom gradients outside the two approved options
Apply the Yellow Glow gradient to large surfaces — it's an accent
